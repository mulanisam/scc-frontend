🚀 QUICK DEPLOYMENT STEPS
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

1. BACKUP DATABASE
   mysqldump -u root -p poultry_db > backup.sql

2. DOWNLOAD BACKEND
   Copy /app/scc-backend-upgraded.zip to your machine

3. PUSH FRONTEND BRANCH
   cd /app
   git push origin feature/ledger-management-system

4. DEPLOY BACKEND
   • Extract zip
   • Copy to backend repo
   • ./mvnw clean package
   • Restart backend service

5. RUN MIGRATION (ONE TIME!)
   curl -X POST http://localhost:8080/admin/migration/ledger \
     -H "Authorization: Bearer <token>"

6. DEPLOY FRONTEND
   • Merge feature branch
   • yarn build
   • Deploy

7. TEST
   • Single sale: /sale/single
   • Payment: /payment-entry
   • Ledger: /ledger

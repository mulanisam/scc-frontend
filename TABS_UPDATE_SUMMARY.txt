Tab 1: BULK ENTRY (Existing)
  • Route-wise comprehensive entry
  • Multiple customers at once
  • SMS notification support
  • Same functionality as before

Tab 2: SINGLE ENTRY (NEW)
  • Quick individual sale recording
  • Auto-calculation (kg × rate)
  • Customer dropdown by route
  • Automatic ledger creation

Tab 3: PAYMENT ENTRY (NEW)
  • Standalone payment recording
  • Customer search with autocomplete
  • Shows current balance
  • Multiple payment modes
  • Automatic balance update

🎮 HOW TO USE
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

1. Navigate to "Sale" in menu
2. You'll see three tabs at the top
3. Click any tab to switch between entry methods
4. Each tab has its own form
5. Switch tabs anytime - forms maintain their state

For Bulk Entry:
  → Use when entering sales for entire route
  → Multiple customers at once
  → Same as before

For Single Entry:
  → Use for quick individual sale
  → Select customer, enter details
  → Submit - done!

For Payment Entry:
  → Use to record customer payment
  → Search customer, enter amount
  → Submit - balance updated!

To View Ledger:
  → Click "Ledger" in menu (new menu item)
  → Select customer
  → View complete transaction history
